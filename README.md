# WORLD 1–1

**[바로 플레이하기](https://lidge-jun.github.io/mario-1-1/)**

슈퍼마리오 1-1의 지형과 진행감을 참고해 만든 브라우저 플랫폼 게임이다. 파이프를 넘고, 블록에서 아이템을 얻고, 적을 밟으며 마지막 깃발까지 달린다. 그래픽, 배경음, 효과음, 게임 로직을 `index.html` 한 파일에 담았다.

설치나 회원가입 없이 플레이 링크를 열고 **플레이 시작**을 누르면 된다. 방향키로 이동하고 `Space`로 점프한다. 점프 키를 길게 누르면 더 높이 뛴다. 소리는 처음에는 꺼져 있으며, 상단 스피커 버튼이나 `M` 키로 켠다.

휴대폰에서는 화면 아래 터치 버튼을 사용한다. 이동 버튼과 점프 버튼을 함께 누를 수 있다. **클리어 데모 보기**를 선택하면 처음부터 끝까지 진행하는 경로를 볼 수 있다. 데모 중 방향키나 터치 조작 버튼을 누르면 그 자리에서 직접 플레이로 전환된다.

오프라인에서는 저장소의 `index.html`을 내려받아 브라우저로 열면 된다. 별도 서버, 패키지 설치, 빌드 과정은 필요하지 않다.

## 조작키

| 동작 | 키보드 |
| --- | --- |
| 좌우 이동 | `←` / `→` 또는 `A` / `D` |
| 점프 | `Space`, `Z`, `↑`, `W` |
| 달리기 | `Shift` 또는 `X`를 누른 채 이동 |
| 불꽃 발사 | 파이어 플라워를 얻은 상태에서 `Shift` 또는 `X`를 새로 누르기 |
| 파이프 진입 | 진입 가능한 파이프 위 중앙에서 `↓` 또는 `S` |
| 시작 / 재도전 | `Enter` 또는 화면 버튼 |
| 일시정지 / 계속하기 | `P`, `Esc` 또는 상단 일시정지 버튼 |
| 처음부터 다시 시작 | `R` — 현재 점수와 진행 상태를 초기화한다 |
| 소리 켜기 / 끄기 | `M` 또는 상단 스피커 버튼 |
| 전체 화면 | `F` 또는 상단 전체 화면 버튼 |

게임 중 다른 창이나 탭으로 이동하면 자동으로 일시정지한다. 돌아온 뒤 **계속하기**를 누르면 이어서 플레이한다.

## 주요 기능

- 물음표 블록, 벽돌, 파이프, 구덩이, 계단, 마지막 깃발과 성.
- 굼바 밟기, 엉금엉금의 등껍질 차기, 불꽃 공격.
- 성장 버섯, 파이어 플라워, 무적 별, 숨겨진 1UP.
- 비밀 지하 코인 방과 지상으로 돌아오는 출구.
- 코인 100개당 목숨 추가, 중간 지점 재시작, 남은 시간 점수 환산.
- 브라우저 저장소에 최고 점수 저장. 계정 간 동기화나 온라인 순위표는 없다.
- 키보드·멀티터치 조작, 전체 화면, 일시정지, 재도전.
- 같은 물리 엔진에서 미리 기록한 조작 입력을 재생하는 클리어 데모.

## 기술 구성

| 항목 | 구현 |
| --- | --- |
| 실행 파일 | `index.html` |
| 화면 | Canvas 2D, 코드로 그리는 픽셀 스프라이트 |
| 게임 로직 | 순수 JavaScript, 고정 60Hz 물리 업데이트 |
| 충돌 처리 | 축별 이동 처리, 주변 타일과 파이프 충돌 검사 |
| 소리 | Web Audio API로 합성하는 배경음과 효과음 |
| 입력 | 키보드 이벤트, Pointer Events 기반 터치 조작 |
| 기록 | `localStorage`에 최고 점수 저장 |
| 외부 의존성 | 없음 — 외부 이미지·폰트·라이브러리 요청 없음 |
| 배포 | GitHub Pages, `main` 브랜치 루트 |

`index.html`이 게임 전체이며, `README.md`는 사용 안내이다. 게임을 수정하려면 `index.html`을 편집한다. `main`에 변경을 올리면 GitHub Pages가 다시 배포한다. 별도의 사용자 정의 빌드 명령이나 의존성 설정은 없다.

## 구현 범위와 안내

Nintendo의 공식 게임이나 공식 프로젝트가 아닌 팬메이드 재현판이다. 원작 ROM을 실행하는 에뮬레이터가 아니며, 그래픽과 물리 동작을 새로 구현했다. 원작의 모든 픽셀, 타이밍, 적 배치가 완전히 동일한 복제본은 아니다.

문제를 발견하면 [이슈](https://github.com/lidge-jun/mario-1-1/issues)에 브라우저와 기기, 문제가 생긴 위치, 재현 순서를 남기면 된다.
